## 📖 Описание

**NOVA RP (GRAND RP) Bot** — программа, которая автоматизирует популярные виды фарма на проекте. Вы запускаете бота, выбираете нужный режим, и он берёт на себя всю рутину, пока вы заняты другими делами. А статистику фарма можно отслеживать вживую прямо в Telegram или Discord.

---

## 🟡 Главный функционал

### ⛽ Нефтевышка
Добыча всех видов топлива: **бензин, керосин, солярка**.

### 🎣 Авто-рыбалка
Идеальное прохождение мини-игры.

### ⛏️ Карьер (добыча руды)
Полный цикл добычи полезных ископаемых.

### 💪 Качалка / тренажёры
Прокачка характеристик персонажа на **100%**.

### 📡 Интеграция с Telegram и Discord
Telegram-бот и Discord-боты для статистики фарма: отслеживайте результаты в лайве, где бы вы ни находились.

### 🚀 Быстрый старт

1. Приобретите ключ на [официальном сайте](#-где-приобрести)
2. Скачайте и запустите программу
3. Введите лицензионный ключ
4. Выберите режим фарма и (по желанию) подключите Telegram / Discord для статистики
